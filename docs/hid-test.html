つながるまでの 3 段階

ブラウザから機器を使うには、次の 3 段階を順に通ります。このページが見ているのは 2 段目までです。

  1. 選べる … 選ぶ画面に機器が出て、選べる（③）
  2. 開ける … 選んだ機器を、ブラウザが使える状態にできる（④）
  3. やり取りできる … ページと、機器に入っているプログラムが、決まった形でデータを送り合う。 ここはページとプログラムの組み合わせ次第なので、このページでは見ません

④ まで緑なのにつながらないときは、3 段目、つまり使っているページの側か、機器に入っているプログラムの側を確かめます。

許可は「サイトごと・機器ごと」に残る

選ぶ画面で一度選ぶと、ブラウザはそのサイトにその機器を使う許可を覚えます。 次からは、選ぶ画面を出さずにつながるページもあります。② はその覚えている機器の一覧です。

  • 同じサイト（このページのアドレスの https://…/ の部分が同じ）のページどうしで、許可は共通です
  • 許可していても、いま挿さっていない機器は ② に出ません
  • 別のブラウザ（Chrome と Edge など）や別の PC では、許可はそれぞれ別です

選ぶ画面は、ボタンを押した直後にしか出せない

ブラウザは、ページが勝手に選ぶ画面を出せないようにしています。ボタンを押してからしばらくたつと出せなくなり、 SecurityError になります。そのときは、もう一度ボタンを押せば出ます。

UIAPduino は 2 つの機器に見える

ふだんの状態（1209:D004。arduino_core_ch32 で作ったプログラムが名乗る番号）と 書き込みモード（1209:B803。UIAP が付けた番号）は、ブラウザから見ると別の機器です。 そのため許可も別々です。ファームウェアを書き込むときに書き込みモードの基板を選んでいても、 ふだんの状態の基板はまだ選んでいない、ということが起きます。

番号の読み方

  • vendorId:productId … 機器の種類を表す番号。1209:D004 のように 16 進で書きます
  • usagePage/usage … 機器が持っている「入り口」の種類。キーボードやマウスは決まった番号、 0xFF00 以上は作り手が自由に使う番号です。UIAPduino はふだんの状態で 0xFF00/0x0001 を持っていて、 Web のページとはここでやり取りします

このページが名前で判定するのは、下の「知っている番号」だけです。それ以外の機器も、番号はそのまま表示します。 お使いの機器の説明書にある番号と照らし合わせてください。
